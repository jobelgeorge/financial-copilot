# Finanical Insight Copilot

AI-powered Financial Analyst Copilot.

## Overview

It is an LLM-powered financial analysis assistant that combines:

- Decoder-only Large Language Models
- Retrieval-Augmented Generation (RAG)
- SQL-based financial analysis
- Tool calling
- Python-based analytics
- Financial document retrieval
- Automated evaluation

## Project Status

## Planned Architecture

User → LLM Agent → RAG / SQL / Python Tools → Financial Data → Answer
